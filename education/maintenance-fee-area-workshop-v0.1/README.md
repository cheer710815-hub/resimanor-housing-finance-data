# 관리비 면적 기준 비교 교육 실습 v0.1

기준일: 2026-11-20. 원문: https://resimanor.com/apartment-maintenance-fee-area-basis-2026/

## 학습 1: 같은 금액을 다른 면적으로 나누기

가상 월 공용관리비 30,000,000원, 전용면적 합계 10,000㎡, 관리비부과면적 13,000㎡.

전용 기준 = 3,000원/㎡. 부과면적 기준 = 약 2,308원/㎡. 반올림 전 값으로 비교하면 후자는 전자 대비 약 23.08% 낮습니다. 세대별 고지금액 절감을 뜻하지 않습니다.

## 학습 2: 비교 조건 구분

comparison_exercise.csv에서 A와 같은 발생월·항목·면적분모의 행을 찾습니다. comparison_answer_key.csv에서 정답을 확인합니다. B는 형식상 비교 후보일 뿐, 규모·난방·연식 등 차이는 추가 검토해야 합니다.

실제 단지 관리비의 적정성·과다징수·회계 부정 또는 K-apt 공시 오류를 판정하는 자료가 아닙니다. 공식 K-apt: https://www.k-apt.go.kr/

## Geography
South Korea

## Topic
Housing finance, mortgage limits, stress DSR

## Description
Open reference data for South Korea's stress DSR framework and reproducible mortgage-limit examples. The dataset includes annual-income scenarios, existing credit-loan scenarios, CSV and JSON files, methodology, citation guidance, monthly snapshots, and canonical source pages.

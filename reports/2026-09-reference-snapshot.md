# 2026-09 Korea Housing Finance and Stress DSR Reference Snapshot

Updated: 2026-09-26

This monthly snapshot packages Resimanor's reusable stress-DSR and mortgage-limit reference data for citation, education, journalism, and software examples.

## Current policy context

For the second half of 2026, the Financial Services Commission's stress-DSR administrative guidance continues through 2026-12-31.

Key reference points used by this dataset:

- Bank-sector DSR comparison assumption: 40%
- Capital-area / regulated-area mortgage stress-rate floor: 3.0%
- Non-capital, non-regulated mortgage easing remains applicable through 2026-12-31 under the announced framework
- Credit loans are subject to the stress rate when total credit-loan balance exceeds KRW 100 million

Always verify current FSC guidance before using these figures for a real loan decision.

# N02 v3 국문 연구 요약 및 발행 전 편집 검토본

**작성 기준: 2026-10-20 | 상태: 발행 전 검토본 — Zenodo v3 미발행**

## 연구 목적

K-apt 공동주택 공용관리비 관련 공식 API 17개에서 보관한 60개 단지의 24개월 자료를 통해, `pay`, `cleanCost`, `guardCost` 응답 숫자의 초기 3개월 대비 마지막 3개월 변화 양상을 탐색적으로 비교한다. 현재 이 세 필드의 **공식 금액 단위·면적 분모는 확인되지 않았다**. 따라서 이번 연구는 세대당 관리비, 원/㎡ 관리비 또는 전국 관리비 수준을 계산한 것이 아니다.

## 자료 범위와 검증

- 기존 20개 단지와 신규 40개 단지, 총 60개 단지의 월 24개월 × API 17종 = **24,480개 보관 응답**을 검사했다.
- 단지·관측월·API 조합의 구조적 누락·중복 및 JSON 필드 구성 변동은 발견되지 않았다. 기존 20개 단지 자료의 파일 SHA-256도 20개 모두 대조·일치했다.
- 첫 3개월과 마지막 3개월의 필드별 숫자 6개가 모두 유효한 양수인 경우만 변화율을 계산했다. **이 기준은 단지와 필드에 따라 분석 대상이 달라지게 한다.**

## 핵심 수치

| API 응답 필드 | 필드별 유효 단지의 중앙값 | 세 필드 모두 유효한 동일 45개 단지 중앙값 |
|---|---:|---:|
| `pay` | +1.93% (50개) | +1.90% |
| `cleanCost` | **+2.24% (50개)** | **-2.09%** |
| `guardCost` | +1.86% (47개) | +1.17% |

**가장 중요한 발견은 `cleanCost`의 부호 역전**이다. 청소비 항목 자체에는 유효하지만 다른 두 항목 중 하나에서 유효하지 않은 단지 5개의 `cleanCost` 변화율이 전부 양수였으며, 공통 45개 분석에서는 이들이 제외된다. 기존 50개 집단에서 단지 한 곳씩 제외하는 50회 검사는 모두 양수 중앙값을 보였다. 반면 공통 45개 집단에 해당 상승 사례를 어느 조합이든 2개 추가하면 중앙값이 양수가 된다. 즉, 특정 한 단지의 수치보다 **표본 선정 규칙**이 중앙값의 방향을 바꾸었다.

## 불확실성과 해석 범위

항목별 유효 표본의 탐색적 부트스트랩 구간(2만 회 재표본추출)은 `pay` -2.99~+3.93%, `cleanCost` -4.31~+4.70%, `guardCost` -3.17~+3.93%이다. 동일 45개 단지의 구간은 각각 -2.94~+2.93%, **-5.36~+3.71%**, -3.17~+3.39%이다. **모두 0%를 포함**한다.

이 값은 비확률 방식으로 선택된 관측 표본을 재표본추출한 탐색적 구간이며, 전국 아파트의 통계적 신뢰구간이 아니다. 관리비가 전국적으로 상승하거나 하락했다는 결론을 내릴 수 없고, 수치 차이의 원인 또한 입증되지 않는다. 결측 또는 0값으로 제외된 표본이 결과에 미친 편향도 정량적으로 확인할 수 없다.

## 원고에 사용 가능한 결론

> K-apt 공식 API로 수집한 60개 단지의 공용관리비 관련 숫자 필드를 분석한 결과, 표본별 중앙값의 방향은 단지 선정·유효성 기준에 민감했다. 특히 청소비 관련 `cleanCost` 필드는 항목별 유효 단지 50개에서 +2.24%였으나 세 필드 공통 45개 단지에서는 -2.09%로 방향이 바뀌었다. 재표본추출 구간은 두 경우 모두 0%를 포함했다. 따라서 이 자료만으로 일반적인 청소비 상승이나 하락을 확정할 수 없다.

## 외부 발행 전 확인해야 할 사항

1. 제공기관의 **문서화된 35개 응답 필드 단위, 적용 면적, 상하위 항목 관계, null/0 의미** 확인. 현재 공공데이터포털 담당자가 부처로 전달했다는 회신만 있고 최종 기술 답변은 없다.
2. 공식 정의가 확인된 필드만 용어와 표를 교정하고, 필요하면 환산과 재계산을 새로 검증한다. 단위 확인 전에는 원/㎡, 세대당 원, 월 총관리비 등으로 바꾸지 않는다.
3. 연구 책임자의 최종 검토·발행 승인을 받은 뒤 **기존 N02 Zenodo 기록의 새 버전**으로만 발행한다. 기존 v2 DOI `10.5281/zenodo.23432629`는 변경하지 않는다.

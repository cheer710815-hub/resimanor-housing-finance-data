## 목적
부산광역시 주택거래가격정보 API와 국토교통부 아파트 매매 실거래가 API에서 같은 지역·계약월의 공개 기록 구성과 계약해제 표시의 가시성을 대조한다. 기관의 오류를 확정하는 연구가 아니다.

## 원자료
- 부산광역시: https://www.data.go.kr/data/15167888/openapi.do
- 국토교통부: https://www.data.go.kr/data/15126469/openapi.do
- 2026년 11월 확보한 보존 API 응답 23개를 기준으로 오프라인 재현성 검증을 수행했다. 계약월이 2026년 1~4월이어도 당시 시점에 수집한 응답이라는 뜻은 아니다.

## 방법
1. 부산시 응답의 `sggNm`에 따라 중구·부산진구를 추출하고 국토부 법정동 코드 `26110`·`26230`과 대응시킨다.
2. 계약연월·계약일·금액(만원)·전용면적(원문 정밀도, ㎡)·층을 기본 비교키로 삼고 단지명·법정동·지번을 정규화해 확장 비교키를 만든다.
3. 비교키가 여러 번 출현한 경우 중복 제거하지 않고 **다중집합 출현 횟수**를 대조한다.
4. 국토부의 `cdealtype=O` 계약해제 표시를 별도 계수한다. 관측 당시 부산시 응답에는 대응하는 별도 해제 표시 필드가 확인되지 않았다.

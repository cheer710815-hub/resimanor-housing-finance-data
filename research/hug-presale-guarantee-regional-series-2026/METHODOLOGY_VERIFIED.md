# HUG 분양보증 발급현황 분석 방법론 v1.0

공식 자료: https://www.data.go.kr/data/15002513/fileData.do (기준일 2026-06-30).

원본 818행·4열을 CP949로 읽고 UTF-8 CSV로 표준화했습니다. 연간(2009~2015)과 분기(2016~2026 Q2)를 분리했습니다. 각 행의 원래 지역명과 원본 수치를 보존했습니다.

## 예외 처리
- 2023년 4분기 '전라' 1행은 전북·전남으로 임의 배분하지 않았습니다. 정규 17개 시도 합계에서 제외하고 원본 보존 및 플래그로 표시했습니다.
- 음수 실적 및 음수 세대수는 원본 기록 그대로 유지했습니다. 음수의 행정적 원인은 원자료 설명만으로 단정하지 않습니다. 집계 시 음수값을 보존하되 '평균 분양가' 등으로 해석하지 않습니다.
- 일부 분기는 17개 시도 중 일부 행이 없으며 누락을 0으로 대체하지 않았습니다.
- 가구당 보증실적(억원/세대)은 금액>0·세대수>0일 때만 계산한 단순 비율로, 실제 아파트 분양가격이 아닙니다.
- 2026년 데이터는 1~2분기 합계이며 연간 실적과 직접 비교하지 않습니다.

## 재현 자료 및 검증 범위

현재 공개된 GitHub 경로에서 확인되는 자료는 [정제 818행 CSV](./hug_presale_guarantee_clean_2009_2026q2.csv), [품질 플래그 31행 CSV](./hug_presale_guarantee_quality_flags.csv), 비교 CSV와 본 방법론입니다. 두 CSV는 동일 품질관리 행 31건을 포함하며, 정제 CSV의 내부 품질 플래그와 양수 금액·양수 세대수에 대한 파생 비율이 일치하는 것을 별도로 확인했습니다.

기존 문서가 언급하던 `build.py`와 `VALIDATION_REPORT.json`은 이 디렉터리의 공개 경로에서 확인되지 않았습니다(2026-11-09 조회). 따라서 **현재 공개자료만으로 HUG 공식 CP949 원본에서 전체 전처리를 다시 수행할 수 있다고 보증하지 않습니다.** 원본부터 재현하려면 실제 전처리 코드·원본 파일의 버전 및 검증 산출물을 추가로 확인해야 합니다. GitHub 공개 파생 CSV에 대한 일관성 검증과 공식 원본부터의 재처리 재현성은 서로 다른 수준의 검증입니다.

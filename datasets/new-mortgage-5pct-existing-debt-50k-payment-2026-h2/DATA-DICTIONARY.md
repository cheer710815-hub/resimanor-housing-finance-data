# Data Dictionary

| Field | Meaning |
|---|---|
| annual_income_krw | Annual income |
| region_group | Regional stress-rate scenario |
| new_mortgage_rate_pct | Actual interest rate assumed for the new mortgage |
| existing_monthly_debt_service_krw | Monthly principal+interest already paid on existing DSR-counted debt |
| dsr_based_new_mortgage_limit_krw | Theoretical new mortgage limit under the scenario |
| new_mortgage_monthly_payment_krw | Monthly payment on the new mortgage at 5.0%, 30 years, equal principal+interest |
| total_monthly_debt_service_after_new_mortgage_krw | Existing monthly debt service + new mortgage payment |

# Release Notes — v1.0

Release date: 2026-10-07

Initial release of the 160-scenario Resimanor DSR mortgage-limit dataset.

Quality targets:
- 160 scenario rows
- no duplicate scenario combinations
- no negative mortgage limits

Interpretation requirement: values are DSR-based theoretical limits, not actual bank approval amounts. The 0.75% regional value is a controlled reference scenario, not a universal fixed official rate.

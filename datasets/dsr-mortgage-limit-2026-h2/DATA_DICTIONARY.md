# Data Dictionary

| Field | Meaning |
|---|---|
| annual_income_krw | Annual income in KRW |
| existing_monthly_debt_service_krw | Monthly-equivalent existing DSR debt-service burden |
| actual_mortgage_rate_pct | Assumed actual mortgage interest rate |
| region_group | Regional analytical scenario |
| stress_rate_pct | Stress rate used in the scenario |
| dsr_assessment_rate_pct | Actual rate + scenario stress rate |
| bank_dsr_limit_pct | Assumed borrower-level bank DSR ceiling |
| term_years | Mortgage term |
| repayment_method | Repayment method |
| annual_dsr_capacity_krw | Income × DSR ceiling |
| annual_remaining_capacity_krw | Capacity remaining after existing DSR burden |
| dsr_based_new_mortgage_limit_krw | Theoretical new mortgage limit based only on the scenario's DSR calculation |
| limit_reduction_vs_no_existing_debt_krw | Reduction versus the same income/rate/region scenario with zero existing burden |
| stress_rate_basis | Interpretation of the stress-rate value |
| calculation_scope | Calculation scope |
| actual_approval_warning | Warning against treating the value as an actual approval amount |

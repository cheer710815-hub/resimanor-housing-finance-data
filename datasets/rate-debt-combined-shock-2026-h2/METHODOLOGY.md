# Methodology — Combined Rate + Existing-Debt Shock 2026 H2 v0.1

## Design

For each fixed annual-income and regional-stress scenario, a clean baseline was compared with two combined-shock scenarios.

Baseline:
- actual mortgage rate 3.5%
- existing monthly debt service 0 KRW

Shock A:
- actual mortgage rate 5.0%
- existing monthly debt service 500k KRW

Shock B:
- actual mortgage rate 5.0%
- existing monthly debt service 1M KRW

## Income groups

- 40M KRW
- 50M KRW
- 60M KRW
- 80M KRW

## Region groups

- capital/regulatory
- non-capital/non-regulatory

## Derived metrics

- limit loss = baseline theoretical DSR mortgage limit - shock mortgage limit
- loss percentage = limit loss / baseline limit × 100

## Main interpretation rule

This analysis isolates a standardized combined financial-stress scenario. It does not establish a causal effect in real borrower populations and does not predict lender approval.

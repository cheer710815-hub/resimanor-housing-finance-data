# Release Notes — 0.1-pilot

Release date: **2026-10-05**

## What is frozen in this pilot

- Event-level schema for housing recruitment notice corrections
- Conservative public-release rule
- Separate verified and partial-evidence status
- Public pilot CSV containing **6 verified events**
- Working seed containing **6 verified + 3 partial-evidence events**
- Public-ready projects represented: **3**

## What is not claimed

This pilot is **not** a complete census of all 2026 South Korean correction notices.

It does not claim:

- a national correction rate
- complete LH coverage
- complete ApplyHome coverage
- a denominator for all 2026 recruitment notices

## DOI decision

No DOI is assigned to version 0.1-pilot.

A DOI release is deferred until a bounded cohort, denominator, coverage period, and source-completeness rule are fixed.

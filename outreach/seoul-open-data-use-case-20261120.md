## 등록 설명안

서울시가 공개한 공동주택 잡수입 자료의 아파트명·코드·일자·수입항목을 비교하여, 단지 이름만을 연결키로 사용하는 경우 서로 다른 코드의 기록이 합쳐질 위험을 설명하는 공개 웹 분석입니다. 2022년 735,394행, 2023년 719,513행을 검토하고, 아파트명·날짜·수입항목 조합에서 서로 다른 아파트코드가 공존하는 사례를 연도별 349개·207개로 집계했습니다. 이 값은 데이터 결합 시 주의해야 하는 **충돌 조합의 수**이며, 회계부정이나 공공데이터 원본 오류 건수를 뜻하지 않습니다. 누구나 분석 방법·한계·재현 저장소를 확인할 수 있습니다.

## 활용 방법 및 시민·교육자 효용

- 공공데이터 정제: 단지명만으로 그룹화하면 다른 관리코드를 혼동할 수 있다는 점을 사례로 설명
- 실무 검증: 단지 이름·코드·날짜·수입 항목을 분리해 데이터 연결 위험 확인
- 시민 해석: 주차장·광고 수입 기록과 개별 세대 관리비 감면액은 다르다는 점을 구분
- 교육 활용: 잘못된 중복 제거 가정이 집계값을 바꾸는 원리를 공개 재현 코드로 확인

## 결과 및 검증 제한

- 2022년 735,394행, 2023년 719,513행 — 총 1,454,907 **기록 행**이며 거래 수나 관리단지 수와 동일하지 않음.
- 아파트명+일자+수입항목이 같고 서로 다른 아파트코드를 포함한 조합 2022년 349, 2023년 207.
- 2023년의 *가상* 이름 기준 중복제거로 제외된 207행의 원본 금액 열 합계 차이는 68,774,624 **원본 필드 단위**이며 원화 손실이나 세대별 관리비 감면액이 아님.
- 공식 회계 오류, 관리비 과다징수, 개별 가구 수익 귀속, 실제 관리비 감면은 본 연구만으로 판단할 수 없음.
- 공개 원문과 GitHub 재현 문서를 출처로 구분하고 새 DOI를 생성하지 않음.
